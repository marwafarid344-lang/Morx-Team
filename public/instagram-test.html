🔑 How to Get an Access Token & Test Reels for Locations

Follow this 2-minute guide to get an Access Token and search Reels for any city or destination.

1 How to get an Access Token in 2 Minutes (Graph API Explorer)

  1. Open Meta's official tool: Graph API Explorer →
  2. In the Meta App dropdown on the right, select: App ID: 28857766263891383.
  3. Under User or Page, select "Get Page Access Token" (or User Token).
  4. Under Permissions, make sure the following scopes are added:
    instagram_basic instagram_manage_contents instagram_manage_messages pages_show_list pages_read_engagement
  5. Click the blue "Generate Access Token" button and log in to authorize.
  6. Copy the token string (starts with EAAG...).
  7. Go back to 1. Connect & Token → paste it → click "Save & Use Token" → then click "Convert to 60-Day Token"!

2 How to get Reels for a specific place (e.g. Alexandria, Dahab)

Under Meta's API rules, you cannot search any private person's posts by GPS coordinates. Instead, Meta provides the official Instagram Hashtag API:

  • When you search for "Alexandria", the API searches #alexandria.
  • It extracts top public videos and reels posted with that location hashtag.
  • Morx Gateway Alternative: In Morx, you can also use GET /api/v1/videos/search?q=Alexandria&duration=short to get short vertical reels/shorts for ANY place worldwide without hashtag quota limits!
